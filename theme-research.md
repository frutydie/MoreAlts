# Theme references

- Themes++: https://github.com/s-n-t09/ThemesPlusPlus
  - Maintained repair edition of Themes+ for Revenge, Kettu, and compatible Vendetta-based clients.
  - Supports custom icon packs, icon overlays, theme-driven icon packs, caching, and compatibility repairs.
  - Installation page: https://s-n-t09.github.io/ThemesPlusPlus/

- Vision Pro reference theme: https://raw.githubusercontent.com/VodkaXMartini/VendettaTheme/main/Vision.json
  - Uses legacy theme JSON with semanticColors, rawColors, plus icon overlays, and spec 2.
  - Includes many icon overlay entries such as ic_logout_24px, ic_settings, ic_search, StatusOnline, and navigation icons.

- Material 3 styles: https://m3.material.io/styles
  - Core style systems are color, elevation, icons, motion, shape, spacing, and typography.
  - Dynamic color is a central Material 3 principle.

- Revenge plugin/theme template: https://github.com/revenge-mod/revenge-plugin-template/blob/main/README.md
  - Modern Revenge Next themes live under themes/ and register with revenge.api.themes.
  - Current MoreAlts work targets the legacy Vendetta/Revenge theme JSON format, which is directly installable in the user's client.
